# 📌Sistema de uma loja gamer

Este projeto foi desenvolvido como trabalho acadêmico para o curso de Análise e Desenvolvimento de Sistemas (IFTM). Ele demonstra a integração de uma aplicação **Java** com um banco de dados relacional **MySQL**.

## 🎯 Objetivo do Projeto
O sistema permite cadastrar, listar e deletar produtos, clientes e fornecedores, aplicando os conceitos de Programação Orientada a Objetos (POO) e comandos SQL.

## 🛠️ Tecnologias Utilizadas
- **Java** (Linguagem principal)
- **MySQL** (Banco de Dados)
- **Maven/Dependências** (Gerenciamento do conector do banco de dados)

## 🗄️ Estrutura do Banco de Dados
Para rodar este projeto, você precisará criar o banco de dados. O script SQL para criação das tabelas está no arquivo `script.sql` neste repositório.

## 🚀 Como rodar o projeto
1. Clone o repositório ou baixe o arquivo ZIP.
2. Importe o banco de dados no seu MySQL usando o script fornecido.
3. Abra o projeto na sua IDE (Eclipse, NetBeans, IntelliJ, etc).
4. Deixe a IDE carregar as **dependências** do projeto automaticamente.
5. No arquivo de conexão (ex: `Conexao.java`), altere o usuário e senha do banco de dados para os do seu computador.
6. Execute o arquivo principal da aplicação.
